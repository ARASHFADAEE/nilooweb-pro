# Nasim Fitness — WordPress Theme

قالب اختصاصی و راست‌چین نسیم فیتنس: صفحه اصلی داینامیک، دوره‌های آموزشی (LMS) و فروش اشتراک ماهانه با درگاه زیبال. بدون وابستگی به افزونه.

## نصب
1. پوشه قالب را در `wp-content/themes/` قرار دهید و فعال کنید (جدول پرداخت‌ها و مسیرها خودکار ساخته می‌شوند). در اولین فعال‌سازی، برگه‌های «درباره من» (`/about/`)، «سوالات متداول» (`/faq/`)، «ارتباط با من» (`/contact/`)، «قوانین و مقررات» (`/terms/`) و «حریم خصوصی» (`/privacy/`) با متن اولیه ساخته می‌شوند (اگر برگه‌ای با همان نامک وجود داشته باشد، دست نمی‌خورد) و «حریم خصوصی» به‌عنوان برگه حریم خصوصی وردپرس تنظیم می‌شود. همچنین اگر هیچ نظری در «نظرات همراهان» نباشد، ۶ نظر نمونه برای صفحه اصلی ساخته می‌شود؛ می‌توانید ویرایش یا حذفشان کنید و با فعال‌سازی دوباره برنمی‌گردند.
2. «تنظیمات ← پیوندهای یکتا» را روی حالتی غیر از «ساده» بگذارید (مثلاً «نام نوشته»).
3. «تنظیمات قالب»: سامانه پیامک (sms.ir یا راه پیام) را انتخاب کنید، کلید API و کد قالب‌های آن را وارد کنید و با «ارسال آزمایشی» امتحان کنید. تا پیامک تنظیم نشود، فقط ورود با رمز عبور فعال است (ثبت‌نام به تأیید موبایل نیاز دارد). گزینه عضویت خود وردپرس لازم نیست.
4. «دوره‌ها ← تنظیمات پرداخت»: کد مرچنت زیبال (یا حالت آزمایشی) را وارد کنید.
5. «دوره‌ها ← پلن‌های اشتراک»: در اولین فعال‌سازی (اگر هیچ پلنی وجود نداشته باشد) سه پلن پیش‌فرض ساخته و منتشر می‌شود: ماهانه ۲۹۰٬۰۰۰، سه‌ماهه ۷۹۰٬۰۰۰ (پیشنهاد ویژه) و شش‌ماهه ۱٬۴۹۰٬۰۰۰ تومان. **قیمت‌ها نمونه‌اند؛ پیش از راه‌اندازی درگاه، اصلاحشان کنید.** (قیمت به تومان، مدت به روز؛ ماهانه = ۳۰)

## ساختار
- `functions.php` — ثابت‌ها و include ماژول‌ها
- `includes/` — تنظیمات قالب، assets، Customizer، منو، نظرات همراهان
- `includes/store/` — ماژول فروشگاه محصولات دیجیتال (افزونه/قالب):
  - `product-post-type.php` — پست‌تایپ `nasim_product` و آرشیو `/products/`
  - `product-meta.php` — نوع، اسلاگ بسته، نسخه، فایل ZIP، changelog، حداقل وردپرس
  - `product-functions.php` — متا، دسترسی دانلود با اشتراک
  - `license.php` — جدول `{prefix}nasim_licenses`، صدور کلید هنگام تمدید اشتراک، فعال‌سازی دامنه
  - `download.php` — دانلود امن ZIP از پنل و پکیج امضاشده برای آپدیت
  - `update-api.php` — REST: `/wp-json/nasim/v1/license/activate|deactivate` و `/wp-json/nasim/v1/update/{slug}`
- `includes/lms/` — ماژول دوره و اشتراک:
  - `course-post-type.php` — پست‌تایپ `nasim_course` و مسیر پلیر `/courses/{slug}/learn/{lesson-id}/`
  - `course-meta-boxes.php` — متاباکس سرفصل‌ها (فصل ← درس، کد Embed، درس رایگان، فایل همراه)
  - `course-functions.php` — سرفصل، دسترسی، پیشرفت، یادداشت‌ها، پاک‌سازی Embed
  - `plan-post-type.php` — پست‌تایپ `nasim_plan` (پلن‌های اشتراک)
  - `subscription.php` — وضعیت اشتراک کاربر و صفحه `/subscription/`
  - `access.php` — دسترسی دستی ادمین: صفحه «دوره‌ها ← مدیریت دسترسی» (اشتراک با پلن/روز دلخواه یا دسترسی دائمی به دوره‌های مشخص)، لغو، ستون و لینک در لیست کاربران، بخش پروفایل کاربر
  - `payments.php` — جدول `{prefix}nasim_payments` و توابع دسترسی به آن
  - `class-nasim-zibal-gateway.php` — کلاینت API زیبال (request / verify)
  - `checkout.php` — شروع پرداخت و callback زیبال
  - `ajax.php` — تکمیل درس، ذخیره درس، یادداشت
  - `admin.php` — صفحه تراکنش‌ها و تنظیمات پرداخت
- `includes/sms/` — پیامک:
  - `sms.php` — انتخاب سامانه (sms.ir یا راه پیام)، ارسال کد و پیامک قالب‌دار، پیامک فعال‌سازی اشتراک (روی هوک `nasim_subscription_extended`)
  - `class-nasim-smsir.php` — کلاینت API پیامک sms.ir (متد Verify و اعتبار)
  - `class-nasim-msgway.php` — کلاینت API راه پیام (متد `send` با کد و پارامترها)
- `includes/auth/` — ورود و ثبت‌نام:
  - `settings.php` — منوی «تنظیمات قالب» (گزینه `nasim_theme_settings`): سامانه پیامک، کلیدها و قالب‌های هر سامانه، خط ارسال راه پیام، پیامک اشتراک، طول/اعتبار کد، فاصله ارسال مجدد، ارسال آزمایشی و نمایش اعتبار sms.ir
  - `otp.php` — نرمال‌سازی موبایل، ساخت/بررسی کد یک‌بارمصرف و محدودیت نرخ
  - `account.php` — مسیرهای `/login/` و `/register/`، هدایت لینک‌های ورود وردپرس به صفحه قالب، فیلد موبایل در پروفایل و ستون موبایل در لیست کاربران
  - `ajax.php` — ورود با رمز، ارسال کد، ورود با کد، ثبت‌نام
- `front-page.php` + `template-parts/front-page/` — بخش‌های صفحه اصلی
- `includes/demo-content.php` — نظرات نمونه صفحه اصلی و پلن‌های پیش‌فرض اشتراک هنگام فعال‌سازی قالب
- `includes/default-pages.php` — برگه‌های پیش‌فرض (درباره، سوالات متداول، ارتباط، قوانین، حریم خصوصی) هنگام فعال‌سازی قالب
- `includes/blog.php` — آدرس وبلاگ، مسیر `/blog/`، عنوان صفحات آرشیو، فهرست مطالب مقاله، مطالب مرتبط و متای کارت‌ها
- `index.php` (وبلاگ، دسته، برچسب، نویسنده، تاریخ، جستجو)، `single.php`، `page.php`، `404.php`، `comments.php`، `template-parts/blog/card.php`
- `single-nasim_course.php`, `archive-nasim_course.php`, `templates/course-player.php`, `templates/subscription.php`, `templates/auth.php`
- `assets/css/tailwind.css` — استایل‌های اختصاصی قالب؛ `assets/css/lms.css` — صفحات دوره و اشتراک؛ `assets/css/auth.css` + `assets/js/auth.js` — صفحه ورود/ثبت‌نام
- `assets/css/app.css` — خروجی build شده Tailwind (در مخزن نگه‌داری می‌شود؛ روی سرور به Node نیازی نیست)

## داده‌ها
- سرفصل دوره: post meta `_nasim_curriculum` (آرایه فصل‌ها و درس‌ها). هر درس یک `id` ثابت دارد تا با جابه‌جایی، پیشرفت کاربران از بین نرود.
- اشتراک: user meta `_nasim_subscription_expires` (timestamp). خرید مجدد به انتهای اشتراک فعلی اضافه می‌شود.
- دسترسی دستی به دوره: user meta `_nasim_course_access` (آرایه شناسه دوره‌ها، دائمی). هر اعطا/لغو دستی با وضعیت `manual` و نام ادمین در جدول تراکنش‌ها ثبت می‌شود.
- پیشرفت/ذخیره/یادداشت: user meta `_nasim_progress_{course}`، `_nasim_bookmarks_{course}`، `_nasim_notes_{course}`.
- پرداخت‌ها: جدول `nasim_payments` (مبالغ به ریال، واحد درگاه).
- محصولات دیجیتال: پست‌تایپ `nasim_product`؛ متا: `_nasim_product_type` (plugin|theme)، `_nasim_product_slug`، `_nasim_product_version`، `_nasim_product_file` (attachment ZIP)، changelog و حداقل وردپرس.
- لایسنس: جدول `nasim_licenses` (یک کلید به ازای هر کاربر). فعال‌سازی‌ها به‌صورت `{slug, domain}` ذخیره می‌شوند؛ هر محصول پیش‌فرض ۱ دامنه رایگان دارد و دامنه اضافه با پرداخت در meta `_nasim_product_extra_slots` برای همان اسلاگ ثبت می‌شود.
- موبایل کاربر: user meta `nasim_mobile` (یکتا، قالب `09xxxxxxxxx`). فقط مدیر (`edit_users`) می‌تواند آن را در پروفایل تغییر دهد.
- کدهای یک‌بارمصرف: transient، به‌صورت HMAC (خود کد ذخیره نمی‌شود).

## وبلاگ
- لیست مقالات در `/blog/` نمایش داده می‌شود. اگر در «تنظیمات ← خواندن» یک «برگه نوشته‌ها» انتخاب شود، همان برگه آدرس وبلاگ می‌شود و `/blog/` به آن هدایت (301) می‌شود.
- فهرست مطالب کنار مقاله به‌صورت خودکار از تیترهای H2 متن ساخته می‌شود (از دو تیتر به بالا).
- تصویر شاخص اختیاری است؛ بدون آن، کارت‌ها طرح جایگزین برند را نشان می‌دهند و صفحه مقاله بدون کاور نمایش داده می‌شود.

## ورود و ثبت‌نام
- ورود با نام کاربری/موبایل/ایمیل + رمز عبور، یا با کد پیامکی (فقط برای شماره‌های ثبت‌شده).
- ثبت‌نام: نام، نام کاربری، موبایل و رمز عبور ← تأیید موبایل با کد پیامکی ← ساخت حساب با نقش `subscriber` و ورود خودکار.
- محدودیت‌ها: هر کد پس از اولین استفاده باطل می‌شود؛ حداکثر ۵ تلاش اشتباه برای هر کد؛ حداکثر ۵ پیامک در ساعت برای هر شماره و ۱۵ پیامک در ساعت برای هر IP؛ ۱۰ رمز اشتباه در ۱۵ دقیقه برای هر IP.
- قالب پیامک در sms.ir باید متغیر کد را داشته باشد (پیش‌فرض `#CODE#`). کلید Sandbox با قالب `123456` برای تست کار می‌کند.
- راه پیام: کد را خود قالب می‌سازد و در فیلد `code` متد `send` می‌فرستد (بررسی کد هم سمت قالب است و از `/otp/verify` راه پیام استفاده نمی‌شود)؛ برای کد ورود/ثبت‌نام در پنل راه پیام قالب نوع OTP بسازید.

## پیامک فعال‌سازی اشتراک
- بعد از پرداخت موفق، تمدید یا افزودن دستی اشتراک توسط مدیر، اگر در تنظیمات فعال باشد و کاربر موبایل داشته باشد، پیامک فرستاده می‌شود. خطای ارسال فقط در لاگ PHP ثبت می‌شود و روند پرداخت را متوقف نمی‌کند.
- متغیرها: `NAME` (نام)، `PLAN` (نام پلن)، `EXPIRE` (تاریخ شمسی پایان)، `DAYS` (روزهای باقی‌مانده). در sms.ir همین نام‌ها متغیرهای قالب‌اند (`#NAME#`)؛ در راه پیام به همان ترتیبی که در تنظیمات نوشته شده، در پارامترهای قالب قرار می‌گیرند (هر پارامتر حداکثر ۴۰ کاراکتر).
- `wp-login.php` برای مدیران در دسترس می‌ماند؛ نوار ابزار وردپرس فقط برای کاربران دارای دسترسی ویرایش نمایش داده می‌شود.
- برای تست محلی بدون پیامک: `define('NASIM_OTP_DEBUG', true);` در `wp-config.php` — کدها در لاگ PHP نوشته می‌شوند. **هرگز روی سایت اصلی فعال نکنید.**

## فروشگاه محصولات (افزونه و قالب)
- آرشیو در `/products/`؛ هر محصول صفحه جدا با دانلود ZIP دارد.
- دسترسی دانلود و آپدیت با **همان اشتراک ماهانه LMS** است (یک اشتراک = دوره‌ها + محصولات).
- بعد از پرداخت موفق، کلید لایسنس در `/subscription/#downloads` نمایش داده می‌شود.
- **لایسنس:** هر کلید اشتراک برای همه محصولات است، ولی **هر افزونه جداگانه یک دامنه رایگان** دارد. دامنه اضافه فقط برای همان محصول (پیش‌فرض ۹۰٬۰۰۰ تومان) خریداری می‌شود.
- REST برای کلاینت افزونه/قالب:
  - `POST /wp-json/nasim/v1/license/activate` — `{ "license", "domain", "slug" }`
  - `POST /wp-json/nasim/v1/license/deactivate` — همان فیلدها
  - `GET /wp-json/nasim/v1/license/status?license=&domain=&slug=`
  - `GET /wp-json/nasim/v1/update/{slug}?license=&domain=`
- فایل نمونه کلاینت: `includes/store/client/class-nasim-license-client.php` — راهنمای کامل در پیشخوان: **محصولات ← راهنمای اتصال**.
- مدیریت لایسنس‌ها: **محصولات ← لایسنس‌ها**.
- لینک دمو هر محصول در متاباکس «لینک پیش‌نمایش (دمو)»؛ اگر پر باشد دکمه «مشاهده پیش‌نمایش» نمایش داده می‌شود.
- **کارت محصول** (`template-parts/product/card.php`): تصویر شاخص، عنوان، زیرعنوان از «چکیده» (یا نام دسته)، آمار فروش/رضایت/پشتیبانی و قیمت. مقادیر در متاباکس «کارت فروشگاه: قیمت و آمار». قیمت خالی = «با اشتراک». فروش = «فروش قبلی» + تعداد کاربران یکتایی که ZIP را دانلود کرده‌اند.
- **دسته‌بندی محصولات**: تاکسونومی `nasim_product_cat` (آدرس `/product-category/slug/`) در منوی محصولات ← دسته‌بندی‌ها.
- **فیلتر آرشیو** با پارامترهای `pcat` (دسته)، `ptype` (plugin/theme)، `sort` (newest, popular, price_asc, price_desc, title) و `q` (جستجو). در موبایل فیلترها در پنل کشویی پایین صفحه باز می‌شوند.

## تیکت پشتیبانی
- کاربر واردشده از `/subscription/?tab=tickets` تیکت ثبت می‌کند (دپارتمان، محصول مرتبط، اولویت، آدرس سایت، پیوست).
- وضعیت‌ها: `open` در انتظار پاسخ پشتیبانی، `answered` پاسخ داده شد، `closed` بسته. پاسخ کاربر تیکت بسته را دوباره باز می‌کند.
- مدیریت در پیشخوان: منوی **پشتیبانی** (با شمارنده تیکت‌های بی‌پاسخ) — فیلتر، جستجو، پاسخ، تغییر وضعیت و اطلاعات اشتراک/لایسنس مشتری.
- پیوست‌ها (تصویر، PDF، ZIP، TXT تا ۵ مگابایت) در `uploads/nasim-tickets/` با دسترسی مستقیم مسدود ذخیره و فقط برای صاحب تیکت و مدیر ارسال می‌شوند.
- اعلان ایمیلی به مدیر (قابل تنظیم پایین صفحه پشتیبانی) و به کاربر در صورت داشتن ایمیل معتبر.
- جداول: `{prefix}nasim_tickets` و `{prefix}nasim_ticket_replies` — کد در `includes/tickets/`.

## قوانین کسب‌وکار
- یک اشتراک به همه دوره‌ها دسترسی می‌دهد؛ درس‌های «رایگان» برای همه باز است.
- کد Embed درس‌های قفل هرگز در HTML کاربر بدون دسترسی قرار نمی‌گیرد.
- پرداخت فقط پس از `verify` سمت سرور و تطبیق مبلغ تأیید می‌شود و callback تکراری اشتراک را دوباره تمدید نمی‌کند.
- زیبال پرداخت خودکار دوره‌ای ندارد؛ تمدید اشتراک توسط خود کاربر انجام می‌شود.
- Embed فقط یک `iframe` با آدرس HTTPS را می‌پذیرد (اسکریپت‌ها و wrapperها حذف می‌شوند). از آپارات، کد «iframe» را کپی کنید.

## توسعه استایل‌ها
```bash
npm install
npm run build:css   # یک‌بار
npm run watch:css   # هنگام توسعه
```
بعد از افزودن کلاس‌های جدید Tailwind در فایل‌های PHP/JS، دوباره build بگیرید.

`index.html`، `article.html` و `course-player.html` نسخه استاتیک طراحی هستند و در قالب استفاده نمی‌شوند.
