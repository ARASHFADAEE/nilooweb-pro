# Niloo Web Pro — WordPress Theme

قالب اختصاصی **نیلو** برای آکادمی آنلاین: صفحه اصلی داینامیک، LMS دوره، اشتراک/خرید تک‌دوره با زیبال، یکپارچگی **اسپات‌پلیر**، سازگار با المنتور.

## نصب
1. پوشه قالب را در `wp-content/themes/` قرار دهید و فعال کنید.
2. «تنظیمات ← پیوندهای یکتا» را ذخیره کنید.
3. **ظاهر ← سفارشی‌سازی ← تنظیمات قالب نیلو** — متن‌ها و تصاویر صفحه اصلی.
4. **تنظیمات نیلو** (پیشخوان) — پیامک OTP و درگاه.
5. **دوره‌ها ← تنظیمات پرداخت** — مرچنت زیبال.
6. **دوره‌ها ← ایمپورت ووکامرس** — انتقال محصولات قبلی به LMS (در صورت نیاز).

## پکیج‌ها (فروش چند دوره با هم)
**دوره‌ها ← پکیج‌های دوره ← افزودن پکیج**: دوره‌ها را تیک بزن، قیمت پکیج را وارد کن و منتشر کن.
- پلن خرید پکیج خودکار ساخته می‌شود (در لیست پلن‌ها مخفی است) و همان درگاه/جدول تراکنش‌ها استفاده می‌شود.
- بعد از پرداخت موفق، همه دوره‌های پکیج دائمی به خریدار داده می‌شود؛ دوره‌های اسپات‌پلیر پکیج یک لایسنس مشترک می‌گیرند.
- صفحه هر پکیج: `/bundle/{slug}/`، آرشیو: `/bundles/`، بخش صفحه اصلی و ویجت المنتور «نیلو · پکیج‌ها».
- قیمت دوره‌ها هم حالا مستقیم از باکس «جزئیات دوره» قابل تنظیم است.

## ورود و ثبت‌نام
یک فرم واحد «ورود یا ثبت‌نام» با موبایل: کد پیامکی ← (فقط برای کاربر جدید) نام. ورود با رمز عبور هم در دسترس است و کاربر از «پنل ← تنظیمات حساب» می‌تواند رمز بسازد.

## ماژول‌ها
- `includes/lms/` — دوره، پلن، پکیج (`bundles.php`)، پرداخت
- `includes/home.php` — صفحه اصلی، خبرنامه (ابزارها ← مشترکان خبرنامه)
- `includes/account-panel.php` — پنل کاربری، تنظیمات حساب
- `assets/css/design.css` توکن‌های رنگ/فاصله · `home.css` صفحه اصلی و پکیج · `panel.css` پنل · `auth.css` ورود
- `includes/integrations/spotplayer.php` — لایسنس اسپات بعد از خرید
- `includes/client-niloo-brand.php` — برند و پیش‌فرض نیلوفر وفایی
